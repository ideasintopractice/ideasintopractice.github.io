# The AI-Powered Project Manager — Companion Website

Free static companion resource website for V31 of the paperback. All five fictional CSV files are included. No accounts, analytics, external scripts, or payments.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `ai-powered-pm-resources`.
2. Upload **the contents of this folder** to the repository root (not the outer folder).
3. Go to **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Select `main` and `/ (root)`, then Save.
5. Open the published URL `https://YOUR-USERNAME.github.io/ai-powered-pm-resources/` and test all six download links on mobile and desktop.
6. Only after verifying the live URL, generate a QR code and insert that URL and QR code into the KDP manuscript.

The URL above is a template, not a live website. Do not print it until deployed and tested.

## Publishing considerations
- The site is free educational companion content, **not** a storefront or e-commerce checkout. GitHub Pages prohibits hosting a site primarily for commercial transactions.
- The PDF facilitator answer key is intentionally **not** published, to keep assessments meaningful.
- No full book PDF or copyrighted manuscript is published on the website.
- Keep the live URL stable after printing. Test each CSV and ZIP link before KDP submission.
- Replace the sample footer wording if the final edition/year changes.
